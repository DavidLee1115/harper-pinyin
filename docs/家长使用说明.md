# 手机使用说明

用手机 Safari 或 Chrome 打开家庭拼音点读台的网址，无需登录，也可以把网址发给同学使用。首次打开需要联网。可以通过浏览器菜单添加到主屏幕。

进入「家长设置」逐项试听示范音，确认发音后再用于练习。当天作业可以粘贴带声调的拼音，先预览再确认保存。预置示例是三行 15 项；新增音节可能没有音频，可在手机浏览器选取替代录音。

作业、练习记录、人工标记和替代录音只保存于当前设备的浏览器，夫妻手机与 Mac 不会自动同步。电脑旧版记录不会自动搬到这个网址。请用普通浏览模式，清除浏览器站点数据会删除本机记录。

网页显示「离线资源已准备」后，页面与 14 个预置音频已缓存到当前浏览器。浏览器可能清理缓存，离线使用效果仍需在你的手机上实测。

切换项目会停止音频；听音选择记录不等于已掌握或朗读准确率。示范音来源见 AUDIO_SOURCES.md。
